Vive Pro 2 Setup — One-Time Steps

1

Install SteamVR + VIVE Console

Both must be installed and updated. Launch SteamVR and confirm the headset shows a solid green icon in the SteamVR status window.

2

Set SteamVR as OpenXR Runtime

In SteamVR: click the ☰ menu → Settings → OpenXR → click "SET STEAMVR AS OPENXR RUNTIME". This is the most common reason WebXR fails on Vive.

3

Use Microsoft Edge (strongly recommended)

Chrome has sandboxing issues with SteamVR/OpenXR. Edge works reliably. If you must use Chrome, launch it with the flag:
--disable-features=XRSandbox
Right-click Chrome shortcut → Properties → add to Target field.

4

Serve on localhost or HTTPS

WebXR is blocked on plain HTTP. Run your backend on port 8000 and frontend on port 8080 as described in previous sessions. localhost counts as secure.

5

Run this check page first

All 5 checks above should be ✓ green before opening FloorViz. Click "LAUNCH TEST VR SESSION" to confirm the headset can actually start an XR session.

Troubleshooting

!

"VR not supported" on Chrome

Switch to Edge, or add --disable-features=XRSandbox to Chrome's shortcut. Chrome has a known sandbox conflict with SteamVR OpenXR.

!

Chrome shows its own VR splash (not FloorViz)

Known bug with Chrome 142+. Switch to Edge. SteamVR must be set as OpenXR runtime — not Windows Mixed Reality or another runtime.

!

ENTER VR button stays disabled

Process a floor plan image first using the Upload button. Rooms must be detected before VR can start. The button auto-enables within 1 second of rooms appearing.

!

Backend offline error

Run in two terminals:
Terminal 1 (backend): cd backend && python -m uvicorn app.main:app --reload --port 8000
Terminal 2 (frontend): cd viewer && python -m http.server 8080
Then open http://localhost:8080/index_v10.html

⚠ Important — hand tracking disabled: The VIVE Console update from January 2025 intentionally blocked WebXR hand tracking to fix a crash bug. Do not request hand-tracking as an optional feature — FloorViz VR v10 already omits it for this reason. Wand controllers work normally.
